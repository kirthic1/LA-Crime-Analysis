## Project Overview
This project analyzes over 900,000 Los Angeles crime records to identify patterns and trends in crime and examine relationships between crime density and socioeconomic factors.
1. Analyzed 900K+ Los Angeles public crime records using Python (Pandas, GeoPandas) to identify patterns and trends in crime timing, geographic locations, and types of crime.
2. Retrieved crime, socioeconomic, and geographic boundary data from public APIs (Socrata, ArcGIS) and performed data preprocessing.
3. Performed geospatial joins to map crime incidents to districts, Service Planning Areas (SPAs), and Countywide Statistical Areas (CSAs).
4. Calculated crime density across geographic areas and performed correlation analyses to examine relationships between crime density and socioeconomic factors, including poverty and unemployment.
5. Developed recommendations for law enforcement resource allocation based on geographic crime patterns and socioeconomic findings.


## Project Structure
| File / Folder | Description |
|---|---|
| [`src/get_data.py`](src/get_data.py) | Retrieves crime, socioeconomic, and geographic boundary data from six public APIs (Socrata and ArcGIS). |
| [`src/clean_data.py`](src/clean_data.py) | Cleans and preprocesses datasets, performs geospatial joins, and prepares data for analysis. |
| [`src/run_analysis.py`](src/run_analysis.py) | Performs statistical analyses, calculates crime density across geographic areas, examines relationships between crime density and socioeconomic factors, and prints the results as formatted tables. |
| [`data/raw/`](data/raw/) | Stores raw datasets. These files are generated automatically when `get_data.py` retrieves data from the public APIs. |
| [`data/processed/`](data/processed/) | Stores processed datasets. These files are generated automatically when `clean_data.py` cleans, transforms, and combines the raw datasets. |
| [`results/visualize_results.ipynb`](results/visualize_results.ipynb) | Imports analytical functions from `run_analysis.py` and uses their results to create bar charts, scatterplots, and geographic maps. Also calculates Pearson correlation coefficients to examine relationships between crime density, poverty, and unemployment. |
| [`results/final_report.pdf`](results/final_report.pdf) | Final project report detailing the methodology, analysis, findings, and conclusions. |
| [`requirements.txt`](requirements.txt) | Python dependencies required to run the project. |

User should not follow the below, as get_data.py will do it for the user.
In order to independently view the data, follow the below steps. 

Crime Data from API
1. Go to https://data.lacity.org/Public-Safety/Crime-Data-from-2020-to-Present/2nrs-mtv8/about_data
2. Click on Export, API Endpoint, API documentation
3. Sign up for App token
4. Use the App token in request to API
5. Use offset and limit parameters to retrieve data in small sets

Poverty Data from API
1. Go to https://geohub.lacity.org/datasets/lacounty::below-poverty-census-tract/about
2. Click on View API Resources
3. Copy the link in GeoService, and truncate it to "query"
4. Use this link url in the request to API, specifying parameter values,
"where": "1=1", "outFields": "*", "f": "geojson", "resultRecordCount": 2000, "outSR": 2229
